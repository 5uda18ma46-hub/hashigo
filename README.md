# Hashigo

練馬の行きつけ4店舗の特売を比べて、「今日みらべる／サミットに寄る価値があるか」を判定する個人用アプリ。

**このリポジトリは画面と価格テキストだけを置く公開側です。**
チラシ画像・PDF・レシート・生の抽出結果は非公開リポジトリ `hashigo-data` にあり、
ここには**絶対に入れません**(著作権と個人情報のため)。

| ファイル | 中身 |
| :---- | :---- |
| `index.html` | アプリ本体。`public/data.json` を読んで表示するだけ |
| `public/data.json` | 毎朝クラウドルーチンが更新する価格データ |
| `robots.txt` | 検索避け |

データの作られ方は `hashigo-data` の README を参照。
